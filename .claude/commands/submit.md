ส่งงานเป็น PR

1. ทำ /check ให้ผ่านก่อน
2. `git status` และ `git diff` — ดูว่ามีไฟล์ที่ไม่เกี่ยวกับเรื่องนี้ปนไหม ถ้ามี ห้ามรวมเข้า commit
3. เขียนคำอธิบาย PR ตาม .github/pull_request_template.md ให้ครบทุกช่อง เป็นภาษาไทย
   - "ทดสอบอย่างไร" ต้องวางบรรทัดสุดท้ายของ just check
   - "แตะของกลางไหม" ตอบตามจริงจาก git diff --name-only main...HEAD
4. commit เฉพาะไฟล์ที่เกี่ยว ข้อความ commit สั้น 1 บรรทัด ภาษาไทยหรืออังกฤษก็ได้
5. **ถามผู้ใช้ก่อน push** แสดงชื่อ branch และรายการไฟล์ที่จะขึ้น
6. push แล้วเปิด PR ด้วย `gh pr create --fill-first` หรือใส่ body ที่เขียนไว้ ถ้าแตะของกลางให้ `--label decision`
7. รัน /review กับ PR ที่เพิ่งเปิด แล้วติ๊กช่อง "AI รีวิวตัวเองแล้ว"
8. รอ CI ด้วย `gh pr checks --watch` แล้วรายงานผล ถ้าแดงให้ทำ /fix-ci
