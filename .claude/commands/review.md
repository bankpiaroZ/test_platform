รีวิว PR: $ARGUMENTS (ถ้าว่าง = PR ของ branch ปัจจุบัน)

อ่าน `gh pr view` และ `gh pr diff` แล้วตรวจตาม checklist นี้ ตอบเป็นภาษาไทย:
- [ ] แตะเฉพาะห้องเดียว? ถ้าแตะของกลาง มีป้าย decision + ไฟล์ docs/decisions/ ไหม
- [ ] ห้อง import ห้องอื่นไหม (import-linter ควรจับ แต่ดูด้วยตา)
- [ ] migration แตะเฉพาะ schema ของห้องตัวเอง? มี downgrade?
- [ ] ตารางใหม่ PK เป็น uuid? natural key เป็น UNIQUE?
- [ ] มีเทสต์ของสิ่งที่เพิ่ม/แก้? เทสต์ยิงฐานจริงไม่ mock?
- [ ] มีค่า config/รหัสผ่าน/ชื่อเครื่องจริงหลุดเข้ามาไหม
- [ ] คำอธิบาย PR ตรงกับ diff จริงไหม

สรุปเป็น: ✅ ผ่าน / ⚠️ ควรแก้ (ระบุไฟล์:บรรทัด) / ❌ ห้ามรวม (เหตุผล)
ห้ามกดอนุมัติหรือรวม PR แทนคน — แค่รายงาน
